### Two machine-specific traps

**Launch from `Y:\Hunter\eco701`.** Claude Code keys its session history and
memory by the working directory, so starting from the `C:\Users\<name>\...`
path files this project under a different key on each machine. The three
memory files written on the home machine are stored locally there and do *not*
sync — read `HANDOFF.md` and this file instead of expecting recall.

**But run `myst build` from the real path, not `Y:`.** MyST 1.10.1 cannot
resolve its own extracted template files through a `subst` mapping. Quarto,
decktape, latexmk and Python are all unaffected. See
[`docs/quarto_workflow.md`](docs/quarto_workflow.md) for the details.

## What changed today, already merged and live

than just an index entry. A "Select decks to publish" step greps
`deploy: true` and writes the survivors to a list; the Quarto render, the
decktape export, the media copy and the Marp build all read it. `deploy: false`
